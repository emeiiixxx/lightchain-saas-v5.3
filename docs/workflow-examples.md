# 画布初始化功能示例

空画布点击一键融合、定向融合、内衣试衣、转3D平铺后，直接展示「主图 → 对应编辑节点 → 示例结果」。不先要求选择素材，用户可以先理解流程，再编辑配置。

一键融合、定向融合、内衣试衣、转3D平铺均展示对应固定示例。示例素材及提示词后补。

当前 Demo 配置维护在 `src/workflow-examples.ts`，素材存放于 `public/assets/workflow-examples/`，现有素材记录见 `docs/workflow-example-images.json`，仅作为实现溯源，不作为具体素材及提示词的验收要求。网页本身不调用生成服务，不写真实生成历史。图片按原始比例载入；节点连接沿用 editorSourceId / generatedByEditorId。载入后整理并适应视图，整组可一次撤销；后续修改、拖拽、生成、删除、整理均沿用画布能力。

节点点击生成时展示对应固定示例结果，宽 360 并保持原图比例，不根据用户后续编辑内容生成真实结果。

读取期间禁止重复触发入口；载入失败保持空画布并允许重试。新上传或切换页面时，过期的示例载入不会覆盖新内容。

抠图初始化行为保持原样。转3D平铺节点及空状态见 `docs/flat-lay-node-source.json`。单图工具栏仍对当前图片创建节点，补主图仍打开单选素材弹窗。未运行浏览器、构建或测试检查。

生成条件、空节点、异常处理及待执行验收统一见 [画布初始化与工作流示例](canvas-initialization.md)。图片右键菜单及 Delete／Backspace 支持删除当前选区；焦点从生成按钮回到画布，输入框保留文字编辑保护。
