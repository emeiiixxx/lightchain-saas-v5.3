# 画布初始化与工作流示例

更新时间：2026-09-16。对应产品需求 P0「5. 画布初始化样式优化」。以下验收项为待执行要求，不代表本轮已完成功能测试。

## 功能规则

**初始页面：**空画布显示「从下方选择一个功能或添加图片，开启您的创作」。入口顺序为抠图、一键融合、定向融合、内衣试衣、转3D平铺，共五个；下方保留独立上传区。内衣试衣右上角显示渐变 NEW 标签，不占按钮布局空间。

**功能入口：**点击一键融合、定向融合、内衣试衣或转3D平铺，直接载入对应的「主图 → 编辑节点 → 示例结果」，自动整理并适应视图，整组支持一次撤销；不先弹出素材选择窗口。抠图保持单张素材选择流程，点击「使用」后进入抠图编辑，取消不改画布。

**固定示例：**一键融合、定向融合、内衣试衣、转3D平铺展示各自对应的固定示例；示例素材及提示词后补。

**一键融合：**参考图可选，最多四张。

**定向融合：**最多三个融合点，支持新增、替换和删除；没有融合点时生成按钮禁用，删除最后一个后立即禁用，新增后恢复。蒙版目前仅回显示例，调整蒙版编辑尚未接入。调整蒙版默认三级文字色，悬停主文字色，不加背景。

**内衣试衣：**模特参考最多一张；当前 Demo 只要求服装主图，描述及模特图可为空。

**转3D平铺：**选择区域只有上装、下装、连身装；示例默认连身装，普通节点默认上装。生成面正面／背面单选，默认正面；生成设置默认自动／2K。有图及空节点均为 280×417。

**已有图片与空节点：**单图工具栏的一键融合、定向融合、内衣试衣、转3D平铺使用当前图片创建对应编辑节点，不加载整套初始化示例或重复添加主图。仅删除主图时保留原位置的空节点，清空对应配置；点击添加主图走单选素材流程，恢复图片和连线。仅删除节点保留图片；删除与恢复支持撤销。

**生成条件与演示边界：**一键融合需要主图和非空指令；定向融合需要主图及至少一个融合点；内衣试衣、转3D平铺需要主图。满足条件时每次追加该功能的固定示例结果，连接实际编辑节点，宽 360 并保持原图比例。修改区域、生成面或提示词不会生成新的真实效果；Demo 不调用 AI、不扣费、不产生真实任务或历史。

**添加图片：**独立上传区桌面尺寸 624×360；点击打开多选素材窗口，也可直接拖入图片。支持 JPG／JPEG／PNG／WebP，单张最多 20 MB，单批最多 20 张，不限制画布总数；确认追加普通图片并选中本批，一次撤销移除本批并恢复原选区，不替换已有主图。

**超限、取消与加载：**多选按剩余名额限制，批量数量超限则整批拒绝；格式、大小或读取失败有提示，成功文件可继续添加。抠图、空节点补主图等单选流程拒绝多文件，取消不改画布。示例读取期间禁止重复触发入口；失败可重试，切换页面或改为上传后，过期示例不覆盖新内容。

**状态与图片操作：**默认、悬停、拖入状态分别使用组件库对应样式，深浅主题均可用。图片右键菜单为下载、复制、复制并粘贴、删除；快捷键文字不加底色容器。选中图片或生成新结果后，Delete／Backspace 删除当前选区，支持撤销／重做；文本输入时只编辑文字，不删除画布内容。

## 验收标准

| 验收项 | 怎么检查 | 通过标准 |
| --- | --- | --- |
| 5. 画布初始化样式优化 | 打开空画布，在深浅主题检查文案、入口顺序、NEW 标签和上传区。 | 五个入口顺序正确；内衣试衣右上角显示渐变 NEW 标签且不挤动布局；上传区桌面 624×360，默认、悬停、拖入状态可区分。 |
| 5.1 四种功能示例 | 分别从空画布点击一键融合、定向融合、内衣试衣、转3D平铺。 | 直接出现该功能的主图、编辑节点、对应结果和两段有效连线，不先弹出素材选择；自动整理并适应视图，图片保持原图比例。 |
| 5.2 对应固定示例 | 分别进入四种功能，确认展示对应固定示例。 | 各功能展示对应固定示例，示例素材及提示词后补；当前不以具体素材或提示词内容作为验收条件。 |
| 5.3 示例加载与撤销 | 连续点击入口、模拟加载失败，加载期间切页或改为上传；成功后撤销／重做。 | 不重复创建示例；失败保持原画布并可重试，过期请求不覆盖新内容；一次撤销移除整套示例，重做恢复图片、节点、配置及关系。 |
| 5.4 抠图及已有图片入口 | 从空画布进入抠图，再分别从单图工具栏进入四种工作流。 | 抠图仍先单选素材并进入抠图编辑；取消不改画布。单图工具栏使用当前图片创建对应节点，不重复主图、不载入整套示例。 |
| 5.5 定向融合限制 | 从无融合点开始，新增至三个、替换、逐个删除至零，再尝试生成。 | 最多三个融合点；新增／替换／删除同步回显。零融合点时生成按钮真正 disabled 且不追加结果；至少一个融合点且有主图时可生成。蒙版只按示例回显验收，不声称已支持编辑。 |
| 5.6 转3D平铺设置 | 展开选择区域，切换生成面，再调整比例、分辨率和撤销。 | 区域枚举严格为上装／下装／连身装；正面／背面单选。普通新节点默认上装，示例默认连身装；默认正面、自动／2K。菜单不被画布遮挡、不误拖节点，设置改变可撤销。 |
| 5.7 空节点及恢复 | 只删主图、只删节点；为空节点补主图，再撤销。 | 仅删主图保留原位空节点并清空配置、隐藏失效输入线；补主图经单选流程恢复图片与连接，取消不修改；仅删节点保留图片。零融合点的定向融合仍禁用生成；所有空节点均不输出结果。 |
| 5.8 生成条件与结果 | 各功能分别使用未满足及已满足条件的配置，连续点击生成。 | 一键融合要求主图＋非空指令，定向融合要求主图＋融合点，内衣试衣和转3D平铺要求主图。通过后每次追加对应固定示例图并连到实际编辑节点，宽 360 且等比；支持后续编辑、整理、删除和撤销，不发起真实 AI、扣费或任务。 |
| 5.9 上传边界与撤销 | 从上传区点击／拖入；测试第 21 张、超剩余名额、超过 20 MB、无效文件、单选多文件、取消及撤销。 | 支持指定格式、单张 20 MB、单批 20 张；数量超限整批拒绝，其他失败有提示并可保留成功项。单选拒绝多文件；取消不改画布，确认追加并选中新图，一次撤销恢复添加前内容和选区。 |
| 5.10 图片菜单与删除快捷键 | 先点生成，再选结果图按 Delete／Backspace；右键操作并撤销，最后在输入框中按删除键。 | 图片菜单仅下载、复制、复制并粘贴、删除，快捷键无底色容器。生成按钮旧焦点不拦截画布删除；删除只作用于当前选区，相关线同步消失、撤销恢复。输入框中删除文字不影响画布。 |
